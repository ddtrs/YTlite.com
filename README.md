# Как получить APK (без установки Android Studio)

GitHub соберёт APK за вас, бесплатно (~15–25 минут).

1. Зарегистрируйтесь на github.com и создайте новый **пустой репозиторий** (кнопка New).
2. Загрузите в него содержимое этого архива: папки `.github` и `PATCHES` и этот README
   (в репозитории: Add file → Upload files; папку `.github` перетащите вместе с вложенными папками).
3. Откройте вкладку **Actions** → слева «Build SmartTube APK (with Rust JSON)» → **Run workflow**.
   (Если Actions просит включиться — нажмите «I understand… enable».)
4. Когда появится зелёная галочка, откройте этот запуск и внизу в разделе **Artifacts** скачайте
   `SmartTube-rust-apk` — внутри zip лежат APK (отдельные для armeabi-v7a, arm64-v8a, x86).
5. Установите на приставку нужный APK по ABI (почти всегда `armeabi-v7a` для старых боксов,
   `arm64-v8a` для современных). Приложение называется как beta-сборка SmartTube
   (`org.smarttube.beta`), поэтому ставится рядом с обычным SmartTube и его не заменяет.

Если запуск упал — откройте красный шаг и пришлите мне его лог.

Замечание: APK подписан отладочным ключом — для личной установки этого достаточно, обновления
из магазина/с сайта SmartTube поверх него не придут.
